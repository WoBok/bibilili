## 这个环境能做什么，不能做什么

| | 状态 |
|---|---|
| JDK 21 + Gradle 8.14 | ✅ 可用 |
| Maven Central | ✅ 可达 |
| **Google Maven（`dl.google.com` / `maven.google.com`）** | ❌ 被出口代理拦截 |
| **Android SDK 下载** | ❌ 同上 |

结论：**这个容器里编译不了 Android 工程**（AGP 取不到）。

对策是把不依赖 Android 框架的逻辑全部下沉到 `:core-bili` 这个纯 Kotlin/JVM 模块，
那部分可以在本地真编译、真跑测试。`:app` 模块的代码写了但**未经编译验证**，
第一次在 Android Studio 里打开时可能需要少量修正。

### 本地验证 core-bili 的办法

主工程的根 `build.gradle.kts` 声明了 AGP，配置阶段就会去取 Google Maven，
所以在这个容器里不能直接 `gradle :core-bili:test`。验证时用一个独立的临时工程：

```kotlin
// settings.gradle.kts: rootProject.name = "core-bili-verify"
buildscript {
    repositories { mavenCentral() }
    dependencies { classpath("org.jetbrains.kotlin:kotlin-gradle-plugin:2.0.21") }
}
apply(plugin = "org.jetbrains.kotlin.jvm")
repositories { mavenCentral() }
dependencies {
    add("testImplementation", "org.jetbrains.kotlin:kotlin-test-junit:2.0.21")
    add("testImplementation", "junit:junit:4.13.2")
}
```

把 `core-bili/src` 拷进去 `gradle test` 即可。走 `buildscript` 取插件是为了绕开
Gradle 插件门户，只依赖 Maven Central。

**在你自己机器上不需要这套**，SDK 齐全时直接 `./gradlew :core-bili:test`。

三处值得单独记一笔的坑，测试里都锁住了：

1. **不能用 `java.net.URLEncoder`** —— 它把空格编成 `+`，而 WBI 要 `%20`；
   十六进制也必须大写。错一个字符签名就废。
2. **历史的稀疏分页** —— 一页 20 条里可能一条 PGC 都没有，所以停止条件必须看
   **游标时间**是否翻过 30 天，不能看「这一页过滤后有没有内容」。
3. **投屏上限 1080P 与投给谁无关** —— 4K/杜比只存在于 DASH，而 DLNA 推不了 DASH。

## 真机反馈修掉的坑（按发现顺序）

这几条都不是「写漏了」，是只有装到手机上才暴露的：

1. **`pgc/` 与 `x/` 的正文字段名不一样** —— 前者放 `result`，后者放 `data`。
   外壳只认 `data` 时，排行榜、剧集详情、时间表全部静默拿到 null。
2. **图片和接口共用 OkHttp** —— 接口客户端挂着 Cookie 拦截器和会 `runBlocking`
   读 DataStore 的 WBI 拦截器，首屏几十张图并发打进去把调度线程拖死。
   图片必须单独一个客户端。
3. **图床地址混着 `http://`** —— `network_security_config` 禁明文，
   于是「有的封面出得来有的出不来」。统一升 https，不要为了看图放开明文。
4. **DASH 的 manifest 是 `file://`** —— 和分片共用 HTTP DataSource 工厂时，
   打开 manifest 那一步就失败，表现是「视频基本都放不了，但详情和选集正常」。
   manifest 要走 `DefaultDataSource`，分片走带 Referer 的 HTTP。
5. **本机播放会污染历史同步的水位线** —— 播放时往库里写一条 `viewAt = now`，
   下次同步第一页就判定「已追上本地」，直接停在原地。
   水位线要单独存，不能取「库里最新一条」。
6. **Kotlin 的块注释可以嵌套** —— KDoc 里写 `x/` 加星号会开一个永不闭合的注释。
