## 0. 产品定位

| 项 | 内容 |
|---|---|
| 产品名 | bibilili |
| 形态 | **Android 原生客户端**（手机为主，横屏全屏播放） |
| 用途 | **个人自用**：只看哔哩哔哩的「影视 / 电视剧 / 纪录片 / 综艺 / 番剧 / 国创」等 **PGC 正片内容** |
| 显式排除 | UP 主投稿视频（UGC）—— 首页历史需要**过滤掉**，不进入本 App 的内容范围 |
| 分发方式 | 不上架应用商店，自编译自安装（见 `04-风险与待决问题.md` 合规章节） |

## 1. 首页（Home）

线框要点：顶部三个 Tab「首页 / 影视 / 番剧」，首页内容自上而下为「历史」「收藏」两个横向区块，各自带「影视页面 / 番剧页面」的入口卡片。

| 编号 | 需求 | 原文依据 |
|---|---|---|
| H-1 | 打开 App 后展现首页页面 | 「1.打开App后展现首页页面」 |
| H-2 | 首页分为**历史**和**收藏**两个区块；**收藏区块的展现逻辑与历史一致** | 「首页分类历史和收藏…收藏页面的展现逻辑和历史一样」 |
| H-3 | **历史必须过滤掉哔哩哔哩 UP 主视频，只展现影视和番剧** | 「这里的历史需要过滤掉哔哩哔哩用户视频…只展现影视和番剧」 |
| H-4 | 需**论证 H-3 用现有 B 站接口能否实现**；自建服务器存数据**不作为首选** | 「第3条的功能考虑如何实现…现有的哔哩哔哩接口等能否实现…当然也可以将数据放在我自己的服务器…但不作为首选」 |
| H-5 | 顶部三 Tab 切换：首页 / 影视 / 番剧 | 线框顶部导航 |
| H-6 | 首页**左滑进入用户页面，右滑返回首页** | 用户界面「1.首页左滑则进入用户页面，右滑则返回首页」 |

> **H-4 的结论见 `02-接口可行性验证.md` §3.1 —— 可以纯客户端实现，无需自建服务器。**

## 6. 全屏播放页面（Fullscreen Player）

| 编号 | 需求 | 原文依据 |
|---|---|---|
| F-1 | 点击屏幕**显示/隐藏**进度条及相关菜单选项 | 「1.播放页面点击屏幕显示/隐藏进度条及相关菜单选项」 |
| F-2 | 左上角：**返回按钮 + 视频名称** | 「2.左上角为返回按钮和视频名称」 |
| F-3 | 右上角依次：**收藏、投屏、菜单（三个点）** | 「3.右上角依次是收藏、投屏和菜单」 |
| F-4 | 三点菜单包含：**定时关闭 / 跳过头尾 / 自动连播 / 快进秒数（名称可换更优雅的）/ 长按倍速**；**居上显示**（非居中）；**选项需记忆** | 「4.点击右上角三个点菜单会显示定时关闭、跳过头尾、自动连播、快进秒数（这个名称可能不是太优雅，可以尝试换一个）、长按倍速（这里可选择的倍速和倍速功能中的可选项保持一致即可）…这里并非居中显示，居上显示即可…这里的功能会记忆」 |
| F-5 | 「快进秒数」和「长按倍速」的设置**同时影响竖屏播放页** | 「快进秒数和长按倍速也会影响播放页面」 |
| F-6 | 长按倍速默认 **2.0x**；双击右快进 / 双击左快退，默认 **10s**，均可在菜单中改 | 「5.长按屏幕可以倍速播放，默认2倍速…默认10s，可以在三个点打开的菜单中设置」 |
| F-7 | **倍速档位固定为：0.5 / 0.75 / 1 / 1.25 / 1.5 / 1.75 / 2 / 2.5 / 3** | 「倍速可以支持0.5、0.75、1、1.25、1.5、1.75、2、2.5、3这些倍速」 |
| F-8 | 三个侧拉菜单：**选集菜单 / 倍速菜单 / 清晰度菜单**（右侧抽屉式） | 「选集菜单　倍速菜单　清晰度菜单」＋截图 |

> **F-4 命名建议**：把「快进秒数」改为 **「双击快进步长」**（或简作「快进步长」），与「长按倍速」并列，语义更准确。待确认。
