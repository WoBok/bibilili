## 1. 设计系统 token

### 1.1 颜色

| 语义 token | 素笺（日） | 素笺·夜（纯黑） | 用途 |
|---|---|---|---|
| `bg` | `#FBF9F4` | `#000000` | 页面底 |
| `surface` | `#FFFFFF` | `#0D0E0F` | 卡片 |
| `surface-2` | `#F5F2EA` | `#16181A` | 弹层、输入框底 |
| `outline` | `#E9E4D9` | `#1C1F21` | 分隔线、卡片描边 |
| `outline-2` | `#E0D9CB` | `#2A2E31` | 芯片描边、强边界 |
| `primary` | `#1F4E46` | `#7FB3A8` | 选中态、主按钮、进度 |
| `primary-container` | `#DCE8E4` | `#16302B` | 主色浅底 |
| `accent` | `#C2410C` | `#E8814F` | 评分、更新标记、危险操作 |
| `on-bg` | `#1A1917` | `#E6E1D6` | 正文 |
| `on-bg-2` | `#6B655C` | `#8E897F` | 次要文字 |
| `on-bg-3` | `#9A948A` | `#5C5850` | 占位、禁用（不承载信息）|
| `player-bg` | `#000000` | `#000000` | 播放器（日夜同）|

**纯黑底三条硬规则**：正文绝不用 `#FFFFFF`（光晕）；卡片绝不用纯黑（无边界）；**阴影一律换成 1px 描边**（纯黑底上投影不可见）。

### 1.2 字体

| 角色 | 字体 | 字号 / 字重 |
|---|---|---|
| 页面大标题 | Noto Serif SC | 20px / 900 |
| 区块标题 | Noto Serif SC | 17px / 700，字距 +1px |
| 卡片标题 | Noto Serif SC | 14px / 700 |
| 正文 | Noto Sans SC | 12.5–13px / 400 |
| 次要 / 元信息 | Noto Sans SC | 10.5–11.5px / 400 |
| 评分、时长、集数 | Noto Serif SC，`tabular-nums` | 随位置 |

数字一律等宽，避免播放进度跳动。

### 1.3 形状与间距

- 圆角：卡片 `12px`／芯片 `14–17px`／输入框 `10px`／弹层 `16px`（仅上两角）／海报 `12px`
- 页边距 `22px`；区块纵向节奏 `26px`；卡片内边距 `14–16px`
- 阴影（仅浅色）：`0 1px 3px rgba(26,25,23,0.07)`
- 触摸目标 ≥ `44×44`

### 1.4 动效

| 场景 | 规格 |
|---|---|
| 通用缓动 | `easeOutQuart`，280ms |
| 页面进出 | 淡入 + 上移 12px，240ms |
| 海报 → 播放页 | `SharedTransitionLayout` 共享元素，360ms |
| 列表入场 | 逐项错位淡入，间隔 30ms，单项 200ms |
| 侧拉菜单 | 从右滑入 300ms，遮罩同步淡入至 40% |
| 详情覆盖层 | 从下滑入 320ms，圆角由 0 → 16px |
| 倍速浮层 | 淡入 120ms / 淡出 180ms |
| 控件显隐 | 淡入淡出 200ms，3s 无操作自动隐藏 |
| 深浅切换 | 颜色动画 240ms，不闪 |
| 返回手势 | `PredictiveBackHandler` 带进度，覆盖层与侧拉菜单跟手 |

素笺的克制：幅度小、时长短、缓动柔，**不做弹性回弹**。

## 2. 登录页

### 2.1 为什么是扫码

| 方式 | 安全 | 体验 | 维护 | 结论 |
|---|---|---|---|---|
| **扫码** | 凭证不经过我们的代码，无人机验证，授权由官方 App 完成 | UI 完全自绘，可做素笺风格 | 接口稳定 | **主路径** |
| WebView 注入官方页 | 需注入 JS 操作官方表单 | 风格割裂 | 官方改版即失效 | **放弃** |
| 手动粘贴 Cookie | 无自动化，零风险 | 需去浏览器复制 | 零 | 兜底，收在「其他方式」 |

### 2.2 流程与状态机

```
generate ──→ 显示二维码（本地 ZXing 渲染，素笺配色）
   │
   └─ 每 2s poll ─┬─ 86101 未扫描 ──→ 「请用哔哩哔哩 App 扫码」
                  ├─ 86090 已扫描 ──→ 二维码淡出、覆盖对勾，「请在手机上确认」
                  ├─ 86038 已失效 ──→ 二维码高斯模糊 + 「已失效，点击刷新」
                  └─ 0     成功   ──→ 取 SESSDATA / bili_jct / DedeUserID，转场进首页
```

- 接口：`passport.bilibili.com/x/passport-login/web/qrcode/generate` → `/poll?qrcode_key=`
- 二维码 180 秒有效，剩 20 秒时边框渐变为 `accent` 提示
- **同机登录**：「用本机的哔哩哔哩 App 确认」按钮，`Intent.ACTION_VIEW` 打开 poll 返回的授权 url。❓ 是否能被官方 App 接管取决于其 App Links 注册，M0 探针验证；不可用时该按钮不显示，只保留跨设备扫码。
- 凭证写入 `EncryptedSharedPreferences`（Tink），**不入 Room、不写日志**
- 页脚一行小字：仅用于个人观看，登录信息只保存在本机

### 2.3 其他方式（底部文字按钮展开）

手动粘贴 Cookie：三个输入框（`SESSDATA` / `bili_jct` / `DedeUserID`），带「从浏览器开发者工具复制」的两行说明。

## 3. 首页

三块，自上而下：

| 区块 | 数据来源 | 交互 |
|---|---|---|
| **继续观看** | `x/web-interface/history/cursor`，筛 `history.business == "pgc"` | 横向卡片，带进度条；点击进播放页并续播 |
| **我的收藏** | `x/space/bangumi/follow/list?type=1\|2` | 全部 / 在看 / 想看 / 看过 芯片筛选；3 列海报 |
| **追番更新** | 同上，`new_ep.index_show` vs `progress` | 有新集未看的条目；按 `new_ep.pub_time` 倒序 |

- 顶部：首页 / 影视 / 番剧 三 tab（衬线，选中带 2px 墨绿下划线）+ 搜索图标 + 头像
- **左滑进入用户页，右滑返回**
- 历史策略：只拉 30 天，本地沉淀 3 个月，7 天清一次 `view_at < now-90d`

### 空态

| 场景 | 文案 | 操作 |
|---|---|---|
| 未登录 | 登录后显示你的观看记录 | 去登录 |
| 30 天内无影视/番剧 | 最近 30 天没有看过影视或番剧 | 去影视看看 |
| 网络失败 | 没能加载观看记录 | 重试 |

细线插画占位，非 emoji、非大图，居中，上下留白充足。

## 4. 影视页

二级 tab：**电影 / 电视剧 / 纪录片 / 综艺**（四个都在）

### 4.1 两行入口

**预设入口行**（我们自己定义，稳定）：

| 胶囊 | 接口 |
|---|---|
| 排行榜 | `pgc/web/rank/list?season_type=N&day=3` |
| 高分 | `pgc/season/index/result` + `order=4` |
| 找片 | 索引筛选页（全量条件）|
| 厂牌 | `index/result` + `producer_id` |
| 地区 | `index/result` + `area` |

`season_type`：电影 2 / 电视剧 5 / 纪录片 3 / 综艺 7

**官方入口行**（动态同步，默认开，可在设置关闭）：
`pgc/page/cinema/tab?name=movie|tv|documentary|variety`（❓ M0 验证）。每个胶囊按跳转链接路由——榜单/索引原生承接，运营片单与活动 H5 走内嵌 WebView。行首带一枚「官方」小标，视觉上比预设行弱一级。

### 4.2 内容流

3 列海报网格，卡片 = 海报 + 角标（大会员/独播/出品）+ 标题 + 副标题（全 N 集 / 更新至第 N 集）。`Paging 3` 分页，触底加载。

筛选页（点「找片」进入）：顶部条件区由 `pgc/season/index/condition` 动态渲染，选中条件以芯片形式常驻，可单个移除。

## 5. 番剧页

二级 tab：**番剧 / 国创 / 时间表 / 我的追番**

- 番剧 / 国创：同影视页结构，`season_type` 1 / 4
- **时间表**：`pgc/web/timeline?types=1&before=3&after=7`。按星期分组，今天整组高亮（`primary-container` 底），每行 = 时间 + 标题 + 更新至第 N 话 + 未看小圆点
- **我的追番**：`x/space/bangumi/follow/list`，想看 / 在看 / 看过 分段筛选 + 排序。与首页「我的收藏」同源，但这里是完整列表 + 状态管理

## 6. 搜索页

- 接口 `x/web-interface/wbi/search/type`，`search_type` = `media_ft`（影视）/ `media_bangumi`（番剧）
- **天然只返回影视和番剧，UP 主视频不会出现**，无需二次过滤
- 需要：WBI 签名 + Cookie 含 `buvid3` + `Referer` 在 `.bilibili.com` + UA 不含敏感子串
- 结构：搜索框（纸感 inset）→ 影视 / 番剧 双 tab → 结果横向卡片（海报 + 标题 + 评分 + 类型·地区·年份 + 集数）
- 空闲态：搜索历史芯片（DataStore，可单删/清空）+ 热搜（`x/web-interface/search/square`，❓ 待验证；取不到则整块不显示）
- 输入防抖 300ms

## 7. 播放页（竖屏）

自上而下：**视频播放 → 视频简介 → 选集**

### 7.1 播放器

- `fnval=4048` + `fourk=1`，DASH 流自建内存 MPD 交给 `DashMediaSource`（**不可用两个 `ProgressiveMediaSource` 拼**）
- 请求必须带 `Referer: https://www.bilibili.com` 与浏览器 UA，否则 403
- 右上角：收藏、投屏（居右排列）；左上角：返回

### 7.2 手势

| 手势 | 行为 | 反馈 |
|---|---|---|
| 双击左半屏 | 快退（默认 10s） | 左侧半圆波纹 + 「-10s」 |
| 双击右半屏 | 快进（默认 10s） | 右侧半圆波纹 + 「+10s」 |
| 长按任意处 | 倍速（默认 2.0X） | 上方偏上浮层「2.0X 倍速播放中」，**无 emoji** |
| 松手 | 恢复原速 | 浮层淡出 180ms |

步长与倍速档位读同一份设置，**竖屏与全屏共用**。

### 7.3 简介

标题、B站评分（`rating.score` + `rating.count`）、类型/地区/年份芯片、两行简介、**详情 ›** 按钮、追剧按钮。

> 本期不接豆瓣评分。

### 7.4 选集（多季）

`pgc/view/web/season` 返回 `seasons[]`（多季）+ `episodes[]`（本季）+ `section[]`（预告/花絮/PV）。

两级结构：**季 tab（第一季 / 第二季 / 预告花絮）→ 集数**。
- 连续剧 / 纪录片：数字方格，4 列
- 电影：单集时整块隐藏选集区，只留「正片 + 花絮」
- 当前集：`primary` 描边 + 文字变色；已看：文字降为 `on-bg-2` 并显示细进度条

## 8. 详情覆盖层

从简介区的「详情 ›」进入，**从下滑入并覆盖播放器下方的整个区域**，播放器继续播放不中断。

- 顶部 drag handle，可下拉关闭；返回键关闭（predictive back 跟手）
- 内容：完整简介（不截断）、类型 / 地区 / 上映时间 / 集数 / 制作方、演职人员横向列表、B站评分与评分人数
- 层级：圆角 16px 仅上两角，`surface` 底，进入时投下一层 12% 遮罩到播放器

## 9. 全屏播放

- 点击屏幕显示 / 隐藏控件，3s 无操作自动隐藏
- 左上角：返回 + 视频名称；右上角依次：**收藏、投屏、三点菜单**
- 底部：播放/暂停、下一集、进度条、右侧三个入口 **选集 / 倍速 / 清晰度**
- 竖屏的三个手势在全屏完全一致

### 9.1 三个侧拉菜单（右侧 292px 纸感面板）

| 菜单 | 内容 |
|---|---|
| **选集** | 季 tab + 集数网格，当前集自动滚入视野 |
| **倍速** | 0.5 / 0.75 / 1.0 / 1.25 / 1.5 / 1.75 / 2.0 / 2.5 / 3.0（九档），当前档 `primary` 底 |
| **清晰度** | 自动 / 8K / 杜比视界 / 大视界4K / 1080P高码率 / 1080P / 720P / 480P。**你有大会员，档位不置灰**；`-10403` 时自动降级并提示 |

### 9.2 三点设置菜单

| 项 | 取值 |
|---|---|
| 定时关闭 | 不开启 / 15 / 30 / 60 分钟 / 播完本集 |
| 跳过片头片尾 | 开关 |
| 自动连播下一集 | 开关 |
| **双击快进步长** | 5s / 10s / 15s / 30s |
| 长按倍速 | 与倍速档位同源，默认 2.0X |

- **菜单居上显示，不居中**
- **全部设置写入 DataStore 并被记忆**，双击步长与长按倍速同时作用于竖屏播放页

「跳过片头片尾」三层降级：接口返回 skip 字段 → 手动按季标记 → 都没有则置灰并说明。

## 10. 投屏

**硬约束：标准 DLNA 任何时候都必须可用，私有协议只做增量。**

```
SSDP/UPnP 扫描（jUPnP）
 ├─ 标准 MediaRenderer ──→ SetAVTransportURI 推 durl 1080P
 │                           └─ 403 → 本机 HTTP 代理注入 Referer/UA 后重推
 └─ friendlyName/manufacturer 命中「云视听小电视 / bilibili」
      ├─ 先按标准 DLNA 试 ──→ 成功即走标准路
      └─ 失败 → 标注「可能仅支持官方投屏」，不阻塞，可另选设备
```

上限 1080P：4K/HDR/杜比只有 DASH，而 DLNA 推不了 DASH，`durl` 最高 `qn=80`。**与投屏目标无关。**

弹层：设备列表 + 刷新 + 扫描中骨架；投屏中显示设备名、音量、退出投屏。

## 11. 用户页

首页**左滑进入，右滑返回**。

- 头部：头像 + 用户名 + 个人简介（`x/web-interface/nav`、`x/space/wbi/acc/info`）
- 设置组：
  - 外观（跟随系统 / 浅色 / 深色）
  - 双击快进步长、长按倍速、默认清晰度
  - 自动连播、跳过片头片尾
  - 显示官方运营入口
  - 清理图片缓存（显示占用大小）
- 底部：**注销**（`accent` 描边按钮，二次确认）→ 清空凭证与本地库 → 回登录页
- 首次打开显示登录页；注销后显示登录页

## 12. 平板适配

同一 APK，`WindowSizeClass` 分支：

| 断点 | 布局 |
|---|---|
| Compact（手机） | 单栏，顶部 tab |
| Medium / Expanded（平板） | **左侧常驻导航栏**（首页/影视/番剧/搜索/我的）+ 内容区 |
| 网格列数 | 手机 3 列 → 平板 5–6 列，随宽度计算 |
| 列表-详情 | `ListDetailPaneScaffold` 双栏 |
| 播放页横屏 | 视频占左 16:9，右侧栏放简介 + 选集，不遮挡画面 |

`minSdk 26`，`targetSdk` 跟随最新。Android 15+ 强制 edge-to-edge，播放页与全屏页需处理 insets 与刘海区；MediaSession 通知需 `POST_NOTIFICATIONS`，前台服务类型 `mediaPlayback`。
