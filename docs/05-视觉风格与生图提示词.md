## 1. 四款风格方案

我按「影视 / 纪录片 / 番剧」这个内容调性，给你 4 个方向，从**克制有质感**到**强个性**排开。

---

### 风格 A · 墨影 Ink Noir　🎬 电影感 / 暗金 / 衬线

> **一句话**：像走进一间放映厅——深黑底、一束暖金、衬线中文标题，海报是绝对主角。

| 项 | 值 |
|---|---|
| 背景 | `#0B0B0F` |
| 表面 / 卡片 | `#16161C` → `#1E1E26` |
| 主色（强调/选中） | `#E8B25C` 琥珀金 |
| 次强调 | `#C4453B` 胶片红（仅用于「正在播放」「直播中」） |
| 主文字 / 次文字 | `#F5F3EF` / `#8E8A84` |
| 分隔线 | `rgba(232,178,92,.14)` 细金线 |
| 中文字体 | 标题 **思源宋体 Source Han Serif**（Bold）／正文 HarmonyOS Sans |
| 英文字体 | 标题 Playfair Display ／数字 用等宽数字 |
| 圆角 | **4px**（锐利，偏电影海报的直角气质） |
| 动效 | 慢、克制。淡入为主（280ms），位移幅度小，选中态用金线滑动 |

**气质**：高级、安静、有「片单」感。纪录片和电影会非常好看。
**风险**：番剧（二次元彩色封面）放进来会略显割裂。
**适合你吗**：如果你主要看电影/纪录片/美剧 → **这是最优解**。

---

### 风格 B · 霓虹深空 Neon Nebula　🌌 赛博 / 辉光 / 高饱和

> **一句话**：深紫夜空 + 品红/青色霓虹辉光，圆润大卡片，动效带弹性。

| 项 | 值 |
|---|---|
| 背景 | `#0A0714` → 径向渐变到 `#160B2E` |
| 表面 / 卡片 | `rgba(255,255,255,.06)` + 1px `rgba(255,255,255,.10)` 描边 |
| 主色 | `#FF2E88` 霓虹品红（呼应 B 站粉，但更暗更饱和） |
| 次色 | `#00E5FF` 电子青 |
| 渐变 | `linear-gradient(120deg,#FF2E88,#7B2EFF,#00E5FF)` |
| 主文字 / 次文字 | `#F2EEFF` / `#9A92B8` |
| 中文字体 | HarmonyOS Sans / 阿里巴巴普惠体（圆润无衬线） |
| 圆角 | **24px**（大圆角，卡片感强） |
| 特效 | 卡片 hover/选中 **外发光 glow**、背景细噪点、进度条辉光拖尾 |
| 动效 | 弹性 `spring(0.6, 380)`，选中态有脉冲呼吸 |

**气质**：年轻、有个性、"一眼就不是官方客户端"。
**风险**：长时间看会有点吵；纪录片/文艺片的封面配霓虹会打架。
**适合你吗**：如果你主要看**番剧/国创** → 很搭。

---

### 风格 C · 素笺 Paper Zen　📖 浅色 / 杂志排版 / 大留白

> **一句话**：像一本电影杂志——米白纸感、墨绿点缀、衬线标题、克制到近乎冷淡。

| 项 | 值 |
|---|---|
| 背景 | `#FBF9F4` 米白纸 |
| 表面 / 卡片 | `#FFFFFF` + `0 1px 3px rgba(26,25,23,.06)` |
| 主色 | `#1F4E46` 深墨绿 |
| 强调 | `#C2410C` 陶土橙（评分、角标） |
| 主文字 / 次文字 | `#1A1917` / `#6B655C` |
| 分隔线 | `#E9E4D9` |
| 中文字体 | 标题 **思源宋体**／正文 思源黑体 |
| 圆角 | **12px** |
| 动效 | 轻、快（160ms），位移 ≤8px，几乎不做缩放 |

**气质**：干净、有阅读感、白天看眼睛舒服。
**风险**：**看视频时浅色底会明显刺眼**——必须做成「浏览浅色 / 播放页强制深色」的混合模式。
**适合你吗**：如果你白天用得多、喜欢"不像视频 App 的视频 App" → 可以考虑。

---

### 风格 D · 流光玻璃 Liquid Glass　💎 毛玻璃 / 海报动态取色 / 强动效

> **一句话**：每部片子的**封面颜色决定整个界面的颜色**，弹层是半透明毛玻璃，动效幅度大而顺滑。

| 项 | 值 |
|---|---|
| 背景 | 深色基底 `#101014`，**叠加当前海报的模糊放大图 + 60% 暗化** |
| 表面 | `rgba(255,255,255,.08)` + `backdrop-filter: blur(24px) saturate(140%)` |
| 主色 | **从海报提取**（Material You / Palette API 动态取色） |
| 主文字 / 次文字 | `#FFFFFF` / `rgba(255,255,255,.62)` |
| 中文字体 | HarmonyOS Sans（Medium 标题 / Regular 正文） |
| 圆角 | **28px**（Material 3 Expressive 尺度） |
| 动效 | 大幅度形变：`SharedTransition` 海报放大成播放器、弹层 `spring` 抛入、列表错峰入场 |

**气质**：最现代、最"活"，每进一部片子界面都换一套配色，个性来自内容本身。
**风险**：**实现成本最高**（动态取色要处理对比度可读性，毛玻璃在中低端机有性能开销）；配色质量取决于海报质量。
**适合你吗**：如果你最看重「良好的交互动画」这条（X-3）→ **这是天花板**。

## 2. 我的推荐

**首选：A「墨影 Ink Noir」为骨架 ＋ D「流光玻璃」的三项能力做增强。**

理由：
1. 你的内容主体是**影视/纪录片**（需求原文第 1 条），A 的电影感调性最贴合，且深色底看视频最舒服。
2. A 的缺点是"静"，而你明确要求「有一定的风格及个性」和「良好的交互动画」——
   把 D 的三件事挂到 A 上正好补齐：
   - **详情页/播放页背景**用海报模糊图 + 暗化（内容自带氛围，不改主色）；
   - **所有弹层/菜单**（选集、倍速、清晰度、三点菜单）用毛玻璃；
   - **海报 → 播放器** 用共享元素转场。
3. 这样主色始终是那一束琥珀金（品牌识别稳定），氛围色由内容提供（每部片不一样），**既统一又不单调**。

**次选**：如果你番剧看得比影视多 → 直接上 **B**。
**不建议一期上**：C（播放场景浅色不友好）、纯 D（动态取色的可读性调试很费时间）。

> 先打开风格画布 https://claude.ai/artifact/Gc2s6EYkJ5YQANqPSVtQPx 看实际效果，再回来定。

## 3. 生图提示词（可直接复制）

### 3.1 使用说明

- 每个风格给了 **1 个风格板（Style Board）+ 3 个关键页面**的提示词。
- **比例**：手机竖屏页面用 `9:19.5`（或 `1080x2340`）；全屏播放页用 `16:9`（`2400x1080`）。
- **建议先只生成 4 个「风格板」**（每个风格 1 张）来定方向，定了再生成该风格的页面图，省时间。
- Codex CLI 调用示例（按你本地实际命令调整）：
  ```bash
  codex "generate an image: <把下面的提示词整段粘进来>"
  ```
- **通用负面提示词**（如果你的工具支持 negative prompt，统一加上）：
  ```
  watermark, logo, signature, text artifacts, garbled text, lorem ipsum, low resolution,
  jpeg artifacts, blurry, distorted UI, misaligned elements, inconsistent corner radius,
  stock photo people, 3D render of a phone in a room, hand holding phone, perspective tilt
  ```
- **通用尾缀**（每条提示词末尾都已包含，若你拆分使用请补上）：
  ```
  Flat straight-on screen mockup, no device frame, no hand, no perspective.
  Pixel-perfect, crisp 1x UI rendering, consistent 8pt spacing grid. Figma-quality UI design.
  ```

> ⚠️ 图像模型渲染**中文字形容易糊**。两个办法：
> ① 提示词里写 `use Simplified Chinese labels, render CJK glyphs crisply`（我已加入）；
> ② 或者把 `Simplified Chinese` 换成 `English`，先只看布局和配色，中文等做真机时再说。**选风格阶段推荐②。**
